# 크롬 웹스토어 등록정보 (v2.0.1)

개발자 대시보드에 붙여넣는 문구를 여기에 둔다. 기능이 바뀌면 이 파일도 같이
고쳐야 스토어 설명과 실제 동작이 어긋나지 않는다.

---

## 간단한 설명 (132자 제한)

```
별도 프로그램을 설치하지 않고도 웹페이지의 동영상을 찾고, MP4 및 M4A로 저장합니다.
```

---

## 자세한 설명

```
웹페이지에서 재생되는 동영상을 찾아 MP4 또는 M4A 파일로 저장합니다.
ffmpeg 같은 별도 프로그램을 설치할 필요 없이 확장 프로그램 하나로 끝납니다.

인천대학교 LMS를 비롯한 대학·기업 온라인 강의 사이트에서 수강 중인 강의를
오프라인으로 보관할 때 쓰도록 만들었습니다.


■ 화질이 떨어지지 않습니다

영상을 다시 인코딩하지 않습니다. 스트림 조각 안에 들어 있는 영상·음성
데이터를 그대로 꺼내 MP4 상자에 옮겨 담기만 합니다.

그래서 두 가지 이점이 있습니다.

· 원본과 동일한 화질·음질 — 손실이 전혀 없습니다
· 매우 빠름 — 14분 분량 강의가 내려받기 포함 몇 초면 끝납니다

오디오만 저장할 때 MP3가 아니라 M4A인 것도 같은 이유입니다. 스트림 속
오디오가 이미 AAC 형식이라, M4A로 담으면 변환이 필요 없습니다. MP3로 바꾸려면
다시 압축해야 해서 느려지고 음질도 나빠집니다.

M4A는 아이폰, 안드로이드, 윈도우, 맥, 주요 브라우저에서 모두 재생됩니다.


■ 사이트를 가리지 않습니다

특정 사이트에 맞춘 것이 아니라 영상 전달 방식 자체를 다룹니다.

· HLS (.m3u8) — 온라인 강의에서 가장 널리 쓰이는 방식
· DASH (.mpd) — 영상과 음성이 따로 오는 경우 하나로 합쳐 저장
· 직접 파일 (.mp4 .webm .m4v .mov 등) — 그대로 내려받기

화질이 여러 개인 영상은 가장 좋은 화질을 자동으로 고릅니다.


■ 영상을 놓치지 않고 찾습니다

페이지 소스만 뒤지는 방식으로는 요즘 플레이어를 놓칩니다. 영상 주소를
자바스크립트로만 가져가고 화면에는 흔적을 남기지 않기 때문입니다.

이 확장은 브라우저에 남은 요청 기록까지 함께 확인합니다. 그래서 영상을 이미
재생한 뒤에 아이콘을 눌러도 찾아냅니다.


■ 사용 방법

1. 강의 영상 페이지를 열고 영상을 한 번 재생합니다
2. 확장 프로그램 아이콘을 클릭합니다 — 팝업이 열리면서 영상을 찾습니다
3. 저장 형식(MP4 또는 M4A)과 파일 이름을 정합니다
4. [다운로드]를 누릅니다

영상이 감지되면 플레이어 오른쪽 아래에 [이 영상 저장] 버튼도 나타납니다.
강의 창이 주소창 없는 별도 창으로 열려 확장 아이콘을 누를 수 없을 때는
이 버튼만으로 저장할 수 있습니다.

찾지 못하면 팝업의 ↻ 버튼으로 다시 검색하거나, [영상 주소 직접 입력]으로
스트림 주소를 붙여넣을 수 있습니다.


■ 그 밖의 기능

· 영상 목록의 미리보기 이미지 — 재생 중인 화면을 그대로 보여줍니다
· 여러 영상이 감지되면 목록에서 선택
· 진행률, 내려받은 용량, 속도를 실시간 표시
· 툴바 아이콘 배지로 감지된 영상 개수와 진행률 확인
· 팝업을 닫아도 다운로드가 계속됩니다
· 자주 쓰는 사이트는 [이 사이트 자동 감지 켜기]로 상시 감지


■ 저장할 수 없는 것

· 유튜브 — 크롬 웹스토어 정책상 지원하지 않습니다
· 넷플릭스 등 DRM(저작권 보호 기술)이 적용된 상용 스트리밍 서비스
· 암호화된 스트림 — 감지되면 명확히 알려드립니다

무리하게 시도해 깨진 파일을 만들지 않고, 처리할 수 없는 경우에는 이유를
분명히 표시합니다.


■ 권한을 최소한만 사용합니다

기본적으로는 사용자가 아이콘을 누른 그 탭에서만 동작합니다(activeTab).
모든 사이트에 대한 접근 권한을 미리 요구하지 않습니다.

자주 쓰는 사이트에서 페이지를 열자마자 감지되기를 원할 때만, 사용자가
[이 사이트 자동 감지 켜기]를 눌러 그 사이트에 한해 권한을 허용합니다.
크롬 설정에서 권한을 회수하면 자동 감지도 함께 해제됩니다.

수집하거나 외부로 전송하는 개인정보는 없습니다.


■ 주의사항

본인이 정당한 접근 권한을 가진 콘텐츠만 저장할 수 있으며, 개인 학습 목적으로만
사용해 주세요. 내려받은 강의 자료를 재배포하거나 공유하는 행위는 저작권 침해에
해당할 수 있습니다. 소속 기관의 학칙과 서비스 이용약관을 함께 확인하시기
바랍니다.
```

## 심사용 비공개 메모

```
새 버전에서 optional_host_permissions("*://*/*")가 추가되었습니다.

이 권한은 설치 시점에 요청하지 않습니다. 사용자가 팝업에서 "이 사이트 자동
감지 켜기"를 직접 누른 경우에만, 해당 사이트 하나에 대해 런타임에 요청합니다.
기본 동작은 activeTab이며 사용자가 확장 아이콘을 클릭한 탭에서만 작동합니다.

영상 CDN은 대부분 Access-Control-Allow-Origin: * 를 반환하므로, 세그먼트를
내려받기 위한 별도 호스트 권한은 필요하지 않습니다. 매니페스트에 선언된
호스트 권한은 lms.inu.ac.kr 하나뿐입니다.

유튜브는 지원하지 않습니다. 유튜브 도메인에 대한 콘텐츠 스크립트나 호스트
권한이 없으며, 유튜브가 사용하는 DASH 서명 URL 처리 로직도 포함하지 않습니다.
DRM(#EXT-X-KEY, ContentProtection)이 적용된 스트림은 코드에서 명시적으로
거부합니다.

원격 코드를 내려받아 실행하지 않습니다. 모든 스크립트는 패키지에 포함되어
있으며, vendor/mux-mp4.min.js는 Apache-2.0 라이선스의 mux.js 7.1.0
빌드입니다(라이선스 전문 동봉).

사용자 데이터를 수집하거나 외부 서버로 전송하지 않습니다.
```
